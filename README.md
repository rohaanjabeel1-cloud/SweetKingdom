# Sweet Kingdom — Match & Magic

A responsive, original candy match-3 browser game.

## Run it
1. Extract `Sweet-Kingdom.zip`.
2. Open `index.html` in a modern browser (Chrome recommended).
3. Tap **Play Now** and swap neighbouring candies to match 3 or more.

No installation, server, database, or API key is needed. Progress is saved in the browser using localStorage.

## Included
- Responsive home screen, kingdom map and match-3 board
- 100 unlockable levels with increasing goals and moves
- Match cascades, special candies, score goals and win/try-again screens
- Hammer, shuffle and extra-move boosters
- Daily coin reward and streak
- Sound effects, settings, persistent coins/levels/stars
- Keyboard/touch friendly buttons and mobile layout

## Project structure
- `index.html` — app screens and layout
- `css/style.css` — responsive design and animations
- `js/game.js` — gameplay, progression, rewards and settings
- `assets/` — reserved for optional future art
